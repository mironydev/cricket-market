# 🏏 Cricket Market

A fantasy cricket team builder built with React. Browse available players, spend your coins wisely, and assemble your dream team.

🔗 **Live Site:** [cricketmarket.netlify.app](https://cricketmarket.netlify.app)

## 🌟 Features

- **Player marketplace** — Browse all available cricketers with stats and pricing
- **Coin/budget system** — Start with a set balance; each purchase deducts the player's cost
- **Team builder** — Toggle between the available players view and your selected squad
- **Toast notifications** — Instant feedback when buying a player or hitting a limit
- **Responsive design** — Works across mobile, tablet, and desktop

## 🛠️ Tech Stack

- [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- CSS / Tailwind CSS
